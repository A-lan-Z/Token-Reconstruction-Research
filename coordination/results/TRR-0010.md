# TRR-0010 — Final public score and decision

What this study learned is a coverage result: expanded fixed-readout training beats the current fixed-readout control in every scoped domain/target cell, while the directional readout loses to its equally trained expanded fixed-readout control. The frozen public evaluation is complete: all 24 method-by-cell predictions passed the public gate, production timing and cost gates pass, the curator materialized labels only after the freeze, and the immutable score completed with 10,000 source-record bootstrap draws. There is therefore no promotion of the directional readout. The score contains no pooled family decision; every claim below is scoped to a domain and target cell.

The strongest result is a coverage/data result, not an isolated direction result. Expanded directional also improves over the unchanged start in every cell, but that comparison combines expanded coverage with the directional parameterization and is descriptive. The current directional checkpoint selects step 0 and is exactly equal to the unchanged start in all four cells. A1+A2 remains a separate historical comparator.

The quality denominator is 128 source-paired records per cell and 127 post-BOS positions per 128-token clip, or 16,256 scored token positions. Exact accuracy counts complete 127-position clips, so its denominator is 128 source records. Public-base and public-LoRA cells use the same source panel within each domain. Token errors count token positions; exact counts count whole clips.

All scored bins have the recorded exposure support, and main-cell benefit and harm safeguards, rather than sparse-bin status, govern the two route decisions.
