# TRR-0020 interim result: strict no-shortlist goal remains active

No effective replacement is established yet. All new algorithms below consider the full128256-token vocabulary and use no per-token shortlist or separate A2 candidate reranker. Prefix weights never train; probability methods optimize only the current input. The scale80 initialization supplies full-vocabulary scores, not a truncated candidate set.

Four complete, source-bound development matrices have frozen before their retrospective scores: residual cancellation64cells; full-vocabulary Adam64; reset-moment optimizer96; diagonal-gradient optimizer48. These use the same8previously opened development inputs. They are not a canonical or fresh confirmation.

The strongest fixed development setting so far is full-vocabulary input-logit optimization with scale80,learning rate0.6,decay0.98,Adam moments0.9/0.995,epsilon1e-12,reset32,256steps,select best continuous cosine objective. It reconstructs:
| Panel | Correct tokens | Exact inputs |
|---|---:|---:|
| Matched prose |252/254|1/2|
| Matched identifiers |78/78|2/2|
| LoRA prose |251/254|0/2|
| LoRA identifiers |78/78|2/2|

This is promising but insufficient to claim near-baseline replacement. Exploratory runtimes are seconds per input, and interrupted/contended measurements cannot establish comparative speed. The diagonal-gradient variant did not improve prose accuracy. Uniform initialization is implemented/tested and can solve identifiers, but its prose results are weaker; do not describe the current strongest setting as lookup-free initialization.

The current dev5 experiment captures the full-vocabulary optimizer on the GPU and tests magnitude-aware losses. It must pass an explicit FP32 execution-equivalence gate and a largest-cell resource check. TF32 is separately labeled numerical behavior. No vocabulary pruning is introduced.

Two memory-guard interruptions are preserved; completed cells were resumed unchanged. The completed raw predictions and receipts are archived with per-member hashes and verified archive contents. See dev1_archive.json through dev4_archive.json, freeze/score files, failed_attempts.json and the resource guards.

The goal remains incomplete until a useful fixed rule passes both canonical setups and the full inherited method matrix is reported. Publication remains subject to the prior automatic approval-review block; local research continues.
