# TRR-0007 exploratory natural-panel evaluation

**Status:** complete exploratory handoff after the public matrix gate and one permitted truth read. The result is source-disjoint, paired, and scored over all 127 post-BOS positions, but it is not a canonical replacement or a dual-benchmark-complete result.

## Finding

Extra positionwise capacity produced a localized Finance improvement point on the improved public bank; broader support alone did not consistently reduce the reconstruction gap. The Finance P0 capacity edge is +0.652 token points and +8.594 exact points, and the Finance LoRA capacity edge is +0.498 token points and +5.469 exact points. These are useful exploratory points, while their corrected exact intervals remain compatible with no gain. The result supports retaining additional capacity on the improved bank as a bounded exploratory candidate and leaves the default unchanged.

The frozen design evaluated 128 fresh Pile and 128 fresh Finance records, pairing each source across public-base and synthetic-LoRA targets. This is 256 unique sources and 512 target observations, not 512 independent sources. Every decoder and the retained reference used the same four cells, and all 127 post-BOS positions per record were scored. A deterministic first-32 public-base subset per domain supplied the bounded A1+A2 diagnostic.

The preregistered primary family contains four direct factorial edges × four domain/target cells × two outcomes × two directions = 64 corrected directional bounds. No corrected primary bound exceeded the +1 token-point or +5 exact-point improvement margin. The only exploratory-useful points are capacity on the improved public bank in Finance P0 (+0.652 token points; +8.594 exact points, 12 gains/1 loss) and Finance LoRA (+0.498 token points; +5.469 exact points, 10 gains/3 losses). Their corrected exact lower bounds are −4.824 and −8.555 points, so neither establishes a material exact improvement. No primary comparison evidenced material harm; token harm was excluded in all 16 direct cell comparisons, while exact harm was excluded in 1/16.

The support-only signal is mixed: broader support at trained-diagonal capacity is −0.400 token points in Finance P0 and +0.265 in Pile P0, while support at residual capacity is −0.074 and +0.141 token points respectively. These are descriptive directions, not a demonstrated support improvement. Lack of a corrected margin is uncertainty, not evidence that the candidate has no value.

## Frozen methods and training evidence

The retained reference is the selected TRR-0006/TRR-0005 enriched trained-diagonal state. Four students cross the current enriched and improved public banks with trained-diagonal and residual MLP-512 capacity. All four fits used the frozen 3,000-step seed-4005 schedule, 1,536,000 post-BOS training draws per arm, fit geometry `[1200,192,2048]`, and validation geometry `[48,192,2048]`. The selected states and their source bindings are immutable in `experiments/TRR-0007/method_freeze.json`.

The residual arm adds a zero-initialized 2048→512→2048 GELU residual over per-position layer-normalized H_i. Fits use full-vocabulary cross-entropy. A2 is a separate bounded diagnostic port and is not used in fitting or primary scoring. The nearly perfect fit/challenge accuracies therefore show optimization of the fitting bank; held-out development is around 0.967--0.970 token accuracy. The 48-record public development set contains Alpaca and Pile, with no Finance records. ## Classification and next experiment

**Classification:** exploratory capacity signal on the improved public bank; no confirmed material exact improvement, no global winner, no default change, and no canonical or dual-benchmark-complete claim. The positive Finance capacity points are useful for prioritization, but their corrected exact intervals remain compatible with no gain. Support alone does not establish a broader-bank benefit.

The next discriminating experiment should be source-disjoint and preregistered before selection: run all four frozen student cells plus the retained reference on an independently sized natural Finance panel, with a matched Pile control if power planning supports it. Use the retained reference, current-bank residual, and improved-bank residual as the primary three-way comparison, and retain improved-bank trained diagonal as the explicit secondary control for the weaker-control-rescue interpretation. Choose the record count from paired exact-discordance/power calculations before selection, retain all 127 post-BOS positions and the same exclusion/gate protocol, predeclare the 5-point exact margin and token harm/cost limits, and interleave or randomize method order for timing. A positive improved-residual result against both the current residual and retained reference would support true improvement; a gain only against the improved-bank trained control would indicate rescue of a weaker control or unresolved exact uncertainty. Advance the candidate only if the independent comparison establishes the predeclared useful gain and meets the cost rule. If an adequately powered comparison excludes the useful gain against the retained reference, or shows that the apparent gain only rescues the weaker improved-bank control, stop prioritizing this capacity extension. The next hypothesis would then be natural-context transfer: test natural public examples against artificial substitutions while matching public token coverage and supervision counts. An inconclusive interval would remain inconclusive, rather than count as evidence for or against either mechanism.
