## Hypothesis

Our learned inverses transform the activation but retain the public
input-embedding table for token scoring.

A reconstruction-specific readout may make the task easier to learn,
while preserving direct full-vocabulary inference.

This is not an assumption that fixed embeddings make perfect recovery
impossible. Nor is an advantage automatically attributable to geometry
rather than additional trainable capacity.

## Bounded comparison

Choose one competent published starting decoder, with exact state and
resource identities recorded before fitting.

Compare:
1. The unchanged starting checkpoint.
2. Continued supervised fitting with its vocabulary readout fixed.
3. The same starting decoder with one adaptable token readout.

Use the same public fitting records, labels, sampling, validation roles,
and comparable optimization opportunities for arms 2 and 3.

Initialize the adaptable readout so the starting decisions reproduce the
competent model. A regularized token-specific correction or an anchored
trainable readout is reasonable; select one design rather than a sweep.

Do not merely add a global linear reparameterization that can be absorbed
into the existing affine map and then call it a richer classifier.
Explain what additional function class the chosen readout supplies.

Keep the added training state and optimizer memory within qualified
resources. More trainable weights are allowed only with explicit accounting;
do not describe a vocabulary-sized learned table as a tiny learned model.

## Training and generalization checks

Use ordinary full-vocabulary, same-position token supervision.

Check whether the adaptable model can improve on public examples that
the starting model gets wrong. Compare fitting and held-out development
curves, not training loss alone.

Protect against unsupported-token degradation. Preserve the public prior
through initialization and one justified regularization or update design.
Report performance by fitting frequency, including absent and rare IDs,
as well as overall natural-text accuracy.

If the apparent gain is only memorization or suppression of uncommon
tokens, treat that as a failure of the tested design.

Do not add teacher ranking, A2 fallback, ensembles, or extra activation
context in this experiment.

## Decision

- A gain over the unchanged checkpoint but not the continued-training
  control is a fitting effect, not evidence for readout adaptation.

- A reproducible gain over the fixed-readout control, without unacceptable
  rare-token harm or deployment cost, supports further investigation.

- Training gains without natural-text generalization reject the tested
  adaptation design.

- An inadequately optimized or underpowered comparison remains
  inconclusive; do not claim that every task-specific readout fails.

Define a useful pilot outcome prospectively. This is mechanism screening,
not an automatic replacement of the registered reference. Do not expand
the experiment repeatedly to obtain a favourable result.
