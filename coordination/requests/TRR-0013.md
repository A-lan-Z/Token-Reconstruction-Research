# Next study — Can focused public practice improve the expanded fixed decoder?

## Question

At the same additional fitting budget, does prioritizing difficult public
token/context examples improve fresh reconstruction more than ordinary
continued training?

Use the rebuilt, preserved expanded B1 from TRR-0012 as the starting model.
Pin its actual selected-state and readout identities from the published
package. It is a new-weight replication model, not the lost PR20 checkpoint.

Own this study end to end. Reuse the verified fitting, restore, prediction,
and scoring paths. Do not create another shared multi-agent implementation
campaign.

## Comparison

Retain:

1. Frozen B1.
2. B1 continued with the reference sampler.
3. B1 continued with one justified hard-example sampler.

Arms 2 and 3 must use the same public pool, architecture, fixed readout,
ordinary full-vocabulary classification loss, comparable training exposures,
and the same validation/selection opportunities.

The primary comparison is arm 3 versus arm 2, not merely versus frozen B1.
No A2 fallback, teacher-ranking objective, learned readout, or new context
architecture.

## Make the sampling intervention informative

First check whether B1 still makes meaningful errors or retains useful
loss variation on the original public fitting bank.

If that bank is effectively memorized, use one modest additional public
correction pool, equally available to both continuation arms. Define it
independently of the newly opened evaluation answers.

Choose difficulty using fitting-side model outputs and legitimate public
labels only. Do not assume that token IDs absent from B0 remain rare in B1.

Use one bounded sampling design, with ordinary-example exposure retained.
Document whether sampling changes the effective training objective or uses
importance correction. Record unique exposure, repetition, and the cost
of computing difficulty scores.

A fit-only improvement is not a successful method. Inspect held-out
development curves and rare/common-token regressions before selecting
the final contender.

## Evaluation

Use a new, unopened natural panel disjoint from fitting, selection, and
previously opened evaluation records and relevant sequence duplicates.

Keep all methods on identical observations. Prioritize Pile exact-clip
recovery and residual token errors; preserve Finance performance as a
safeguard. Pair sources across the declared target conditions without
counting them as independent sources.

Define a feasible useful-gain threshold prospectively. Do not reuse a
+1-point token threshold when the baseline's entire error rate is smaller.

Include a bounded common A1+A2 subset so the remaining quality gap stays
visible. Keep its denominator separate.

Freeze model choices and predictions before scoring. Report paired gains,
regressions, uncertainty, fitting cost, and matched inference cost.

## Ownership and preservation

Use a task-owned branch from the published TRR-0012 work; verify task-name
availability. No merges, global-registry changes, or use of P03's holdout.

Retain logical evaluator/reconstructor separation without requiring
cross-agent handoff at every step. Agent 2's transfer study is independent.

Run an early end-to-end synthetic smoke check. Save model bytes durably
during fitting and verify the restore package before final evaluation.
Reuse valid evidence unless its code or inputs changed.

Coordinate compute and source exclusions. No paid compute.

End with one decision: focused sampling improves on equal-budget ordinary
learning, ordinary continuation explains the gain, or neither provides a
useful fresh-data improvement. Do not automatically launch another sampler.
