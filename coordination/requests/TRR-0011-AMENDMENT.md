# Amendment to TRR-0011 — Independent confirmation and explanatory transfer diagnostics

## Reason for the amendment

The committed PR20 evidence shows evaluation/source overlap with
checkpoint-selection validation.

The validation audit identifies the earlier TRR-0009 panel as the
384-record checkpoint-selection set. PR20's final Pile panel has identical
ordered record-ID and final-sequence fingerprints for all 128 records.
Finance overlap is also verified; enumerate its full extent from the
available metadata.

Preserve PR20's predictions, scores, and historical decision receipts.
Append a factual interpretation correction: affected results are
selection-overlapping development evidence, not independent
text-generalization estimates.

This is not an allegation that inference read answers or that validation
records were used for gradient fitting.

No retraining or checkpoint reselection is authorized.

## Agent 2: own genuine frozen-model confirmation

Continue with the selected expanded-fixed and current-fixed checkpoints.

Before new evaluation truth is opened, independently verify zero overlap
with all accessible:
- gradient-fitting banks;
- checkpoint-selection and calibration data;
- previously opened development/evaluation sources;
- relevant duplicate source and token-sequence identities.

The TRR-0009 selection manifest must be explicitly included because it
became checkpoint-selection validation for PR20. Do not assume an earlier
exclusion ledger already covers every later use of a dataset.

Use matching fingerprint conventions and record intersection counts.
Add a focused regression check demonstrating that reused validation
records are rejected. This is a targeted correction, not a new platform
or broad infrastructure audit.

If a panel is already selected but unscored, check it before proceeding.
If results have already been opened, preserve them and label their actual
status; do not quietly replace records and call the combined result fresh.

If published source ranges are exhausted, register a compatible extension
before selecting replacements. Do not recycle validation examples to meet
a requested sample size.

Keep the frozen model states and primary comparison unchanged. Include
A1+A2 on a prospectively chosen common subset, with its denominator explicit.

After predictions are frozen and scored, report the paired error inventory:
both correct, only expanded-fixed correct, only A1+A2 correct, both wrong.
Inspect candidate ranks, confusion types, fitting support and positions
where available. Keep A1+A2 proposal failures distinct from direct-decoder
ranking failures.

Distinguish reproducibility failure, genuine generalization loss, and
imprecise evidence. A nonpositive confidence lower bound alone does not
prove that the original improvement disappeared.

## Agent 1: package, overlap record, and bounded transfer study

First provide the immutable inference package, state/resource identities,
and replay checks on already-opened material. Produce the metadata-only
overlap report and corrected interpretation for PR20 without altering
its historical outputs.

Then use a separate public diagnostic set to examine the frozen expanded
decoder across a small set of controlled public-prefix changes.

Hold source text, tokenizer, architecture, cut and numerical execution
constant where the comparison requires it. Vary target weights and update
location deliberately. Include a compatible independently adapted target
where practical; label artificial perturbations separately.

Keep the unavailable target-prefix weights on the evaluator side.
The deployed decoder remains frozen and receives only permitted inputs.

Separate:
- tokens already wrong under the public target;
- previously correct tokens broken by target changes;
- tokens improved by those changes.

Measure activation distortion relative to the relevant decision margin,
and compare its usefulness with unnormalized distortion and parameter
distance. Use geometry consistent with the actual scorer: cosine matching
and learned-classifier margins are not interchangeable with raw L2 distance.

Any margin thresholds or predictive rules chosen on development updates
must be tested on held-out update families. Do not present an evaluator-only
quantity involving true tokens as a deployable confidence certificate.

No new teacher objective, adaptive decoder, readout variant, coverage
expansion, or numerical-inversion campaign is authorized by this amendment.

## Shared constraints and outcome

Keep the confirmation panel and its hidden outcomes separate from
diagnostic development. Preserve P03's sealed holdout and existing
worktree, resource and no-merge boundaries. No paid compute.

The output should establish:
1. Whether the selected frozen decoder generalizes to genuinely unused text.
2. Which remaining errors distinguish it from A1+A2.
3. Whether controlled target changes reveal a predictable transfer weakness.
4. One evidence-backed intervention worth testing next.

The ultimate objective remains a better practical reconstruction method.
An explanatory statistic is useful when it predicts behaviour or guides
a discriminating improvement experiment—not merely because it correlates
with errors already examined.
