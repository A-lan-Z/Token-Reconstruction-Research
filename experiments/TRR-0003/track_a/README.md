# Track A pilot: reverse public-prefix fixed point

This arm tests a checkpoint-only inverse at cut 4 of the pinned
Llama-3.2-1B-Instruct public model.  A Llama pre-norm block is treated as

    a = x + Attention(RMSNorm(x))
    y = a + MLP(RMSNorm(a))

Given the observed boundary state y, the runner reverses layers from 3 to 0.
Within each layer it first inverts the MLP residual and then the attention
residual.  Each residual equation uses a fixed damped update

    x <- (1-damping) x + damping (target - public_branch(x))

starting at the observed target.  The public branch is evaluated once for the
proposal and once again for the residual diagnostic, so the reported branch
evaluation count is twice the iteration budget.  The estimate is projected by
an exact chunked scan of the public embedding table, with squared Euclidean
distance and token-ID tie breaking.  No lens, fitted calibration, auxiliary
training, tokenizer, target weights, source text, or candidate prefix
simulation is available to this process.

Iteration zero is a required identity baseline: it sends the observed
boundary state directly to the same public embedding projection after replacing
the known BOS row with the public BOS embedding.  It is not an inverted result.
The frozen ladder is 0, 1, 2, 4, 8, 16, 32, with damping 0.5, top-K 16,
vocabulary chunks of 8192, and one unpadded valid record per call.  The
caller checks that every valid row is right padded and that its valid position
IDs equal arange(valid_length).

The matched public_base cells are a numerical control for whether the public
inverse can solve a state generated by the same public prefix.  The paired
public_lora_2601 cells are the shifted-target diagnostic; their target weights
are not loaded by this arm.  Both are exploratory controls and remain separate
from canonical dual-benchmark replacement claims.

preregistration.json is the method-state registration.  The runner binds
each prediction to the panel bytes, registration bytes, verified public
resource manifest, loaded prefix state digest, embedding-table digest, and
all imported executable source files.  It writes only the highest-iteration
prediction to the shared footing path when all eight records are selected.
The complete iteration ladder and per-position continuous/discrete cycle
residuals are written under the separate diagnostic root.  Truth and source
material are never opened by the runner; accuracy fields therefore remain
null until an independent evaluator validates completeness and integrity.
