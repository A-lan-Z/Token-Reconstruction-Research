# TRR-0003 footing handoff

This footing is a retrospective public development panel for the initial TRR-0003 probes. It is a shared input contract, not a canonical benchmark result. The panel contains 16 distinct records per condition: eight Pile rows and eight Finance chat-template rows, paired across `public_base` and `public_lora_2601`.

The exact panel is `experiments/TRR-0003/footing/panel.json` (SHA-256 `d1810330f53ebb7e149be45b8c07414e09d30b31b68c7c09d24df3854fec7333`). Pile cells use `[8,40,2048]` activations with all 40 positions active; Finance cells use `[8,128,2048]` activations with the source right-padding masks and position IDs. Pile contributes 312 scored post-BOS positions per cell. Finance has 770 active positions including BOS and 762 scored positions per cell. The loader checks source asset sizes and hashes and selects rows `0:8` from the existing 32-row public activation assets:

- `outputs/TRR-0002/public-calibration/observations/public_base_cut4.safetensors`
- `outputs/TRR-0002/public-calibration/observations/public_lora_2601_cut4.safetensors`
- `outputs/TRR-0002/configuration-search/public-finance/observations/public_base_cut4.safetensors`
- `outputs/TRR-0002/configuration-search/public-finance/observations/public_lora_2601_cut4.safetensors`

The Pile panel IDs are the first eight rows of the existing public-development ledger and were checked against the prior `inverse_train`, `target_update_train`, and blind evaluation IDs. Conditions reuse identical ordered records, masks, and positions. Track A receives no fitted resource. Track B's immutable contract is recorded in `plan.json`: fit on the 128-record `inverse_train` split and validate on development ledger rows `8:32`; the panel rows `0:8` are forbidden for fitting and validation is disjoint from them. Any Finance fitting set must be declared separately. New methods remain `NOT RUN` in both canonical dual-benchmark setups, so this footing does not claim comparison completeness.

`public_lora_2601` is one synthetic shift diagnostic. Existing generation metadata records rank 4, alpha 4, layers 0–3, q/v projections, seed 2601, 30 steps, batch 8, learning rate `7.5e-4`, zero weight decay, and clip 1.0. The update state is `outputs/TRR-0002/public-calibration/updates/public_lora_2601.safetensors`, 427632 bytes, SHA-256 `eea7bb49f801b61df2e26a8f59af7c3096f6f3a2604404e16e589443bcfba595`. On scored paired observations, relative L2 drift is 0.36005 for Pile and 0.36805 for Finance; mean per-token relative drift is 0.36357 and 0.37100, with mean activation cosine 0.93746 and 0.93235 respectively. The target update is unavailable to reconstruction. These measurements show a material single synthetic shift and are not evidence about full SFT transfer.

The reusable comparator states are the historical public A1 lens `outputs/TRR-0002/blind/reconstructor_input/public_a1_lens.pt` (SHA-256 `33b825dff8eb13cfe877a55bb14e3404c4e3f66355e271fb29004b2d49f4a742`) and the existing cut-4 residual-affine inverse `outputs/TRR-0001/reconstructor_public/inverses/cut4.safetensors` (SHA-256 `9e2487f85057748130bf87b2aad0a883f3c36dfc052eefd83c0f5c35497a24e3`). `scripts/trr0003_footing_compare.py` provides the public-only comparator runner for historical A1 rank-one, direct inverse rank-one, and the frozen A1+A2 K256 port. It records model preparation separately, per-cell cold versus steady timings, candidate simulations, prefix commits, and peak memory. Its freeze and scorer path uses `validate_before_truth` only after the exact style × condition × method artifact set, panel binding, method-state hashes, and executable-code hashes pass.

The footing verifier closes the previously observed gaps used by this pilot. It rejects unlisted files added after a receipt, unsafe or out-of-root receipt paths, symlinks, missing or extra prediction cells, malformed masks, wrong BOS/padding, non-finite scores, out-of-vocabulary predictions, and changed panel/state/code bytes. The test suite covers these cases and monkeypatches the private sidecar loader to show a missing frozen prediction fails before that loader is called. `PYTHONPATH=src pytest -q tests/test_freeze_and_separation.py tests/test_trr0003_footing.py` passed 10 tests; `PYTHONPATH=src:scripts pytest -q` passed 100 tests. The default `PYTHONPATH=src` full collection still has three legacy tests that import scripts as top-level modules; this is unrelated to the footing change.

Live CPU-only preflight was captured in `inventory.json`: `/usr/bin/python3`, Python 3.12.3, torch 2.10.0+cu128, CUDA 12.8, transformers 5.3.0, safetensors 0.7.0; RTX 5080 with 16,303 MiB total and roughly 12,087 MiB free at capture; 30 GiB host RAM with roughly 28 GiB available; 297 GiB free on the repository filesystem. No paid compute or footing GPU run was used. The largest qualification cell is Finance `[8,128,2048]`, with a 4,194,304-byte BF16 activation lower bound before model and candidate state.
