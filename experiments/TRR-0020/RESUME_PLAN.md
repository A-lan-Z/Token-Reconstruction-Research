# Restart orchestration
Dev2 and dev3 were independently stopped by the memory guard when other device usage removed the safety margin. No rows or configurations are removed, no batches or arithmetic change.
The task-local resume script verifies all saved receipts against the original scientific binding and calls the original engine for every missing cell. It repeats one largest128-position representative configuration before continuing, while retaining all twelve original synthetic variant qualifications. This avoids spending each available GPU window redoing completed qualifications. The resume script has its own hash in the final freeze. All matrices must still complete before labels open. The guard and admission thresholds are unchanged. Interrupted timing is not valid comparative performance evidence.
