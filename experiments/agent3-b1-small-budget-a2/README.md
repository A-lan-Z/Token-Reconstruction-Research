# Reproduction

Run from the task worktree with Python3.12, torch2.10.0, numpy1.26.4, safetensors0.7.0 and scipy. The task copy of the actual package is at `outputs/agent3-b1-small-budget-a2/assets/package`; every dependency is hash-bound in package-files.json. The original Windows secondary package is preserved at `/mnt/c/Users/alanz/Token-Reconstruction-Backups/TRR-0012`. Loader/readout/state hashes are verified on every invocation. The historical public lens is `outputs/agent3-b1-small-budget-a2/assets/public_a1_lens.pt`; the native readout/loader verification does not require a target model.

1. `python3 -m pytest -q tests/agent3_shortlists`
2. `python3 -m scripts.agent3_shortlists.smoke --package outputs/agent3-b1-small-budget-a2/assets/package --lens outputs/agent3-b1-small-budget-a2/assets/public_a1_lens.pt --reference reference/strict_bos/round001_teacher.py --output <new-smoke-receipt.json>`
3. Evaluator-only TRR-P12 prepares one prefix-changing target trajectory and paired sanitized observations; the exact phase commits, commands, states/backups and source exclusions are linked in input-matrix.json, shared-target-verification.json and shared-capture/. No target training is duplicated here.
4. For each domain/stage, import its released observation manifest with `python3 -m scripts.agent3_shortlists.import_observations --release <release.json> --output <new-cell-input-dir>`. The manifest supplies `domain`, integer `stage`, ordered opaque `record_ids`, and `observations` binding (`path`, `bytes`, `sha256`). The task always uses the first 32 records.
5. For each cell run `python3 -m scripts.agent3_shortlists.watchdog --output <new-watchdog-dir> -- python3 -m scripts.agent3_shortlists.predict --contract <cell-input-dir>/contract.json --package outputs/agent3-b1-small-budget-a2/assets/package --lens outputs/agent3-b1-small-budget-a2/assets/public_a1_lens.pt --reference reference/strict_bos/round001_teacher.py --output <new-cell-output-dir>`. Default CPU record1,2threads,FP32,TF32off. Full logits are generated and hashed; retain nested top256 IDs/scores and top1 predictions. Watchdog records full command, commit, elapsed time, sampled peak RSS, RAM and logs. The synthetic32-record qualification is not scientific evidence.
6. Compute drift from all eight contracts: `python3 -m scripts.agent3_shortlists.drift --contracts <eight-contract-paths> --output <drift.json>`.
7. Freeze the full 16-output matrix: `python3 -m scripts.agent3_shortlists.evaluate freeze --receipts <eight-cell-receipt-paths> --output <freeze.json>`. This validates completeness, paired identities, input/output integrity, same model/code/numerical identities, and candidate ordering before any truth is read.
8. Only after freeze, the evaluator materializes truth for the same first 32 sources/domain. Supply a manifest with `domains.pile` and `domains.finance`, each with the exact ordered `record_ids` and a bound safetensors `artifact` containing only int64 `token_ids[32,128]`. Then `python3 -m scripts.agent3_shortlists.evaluate score --freeze <freeze.json> --truth-manifest <evaluator-truth-manifest.json> --output <result.json>`. It revalidates the entire freeze before reading that manifest.

All outputs are create-only. A failed attempt gets a separate directory and remains excluded; no scientific output may be silently overwritten. The system never inserts labels into candidates. Any budget selected by these outcomes is development-only. The maintained-model-prefix integration gap prevents an intended tracking hybrid here; no A2 speedup is inferred from candidate counts.
