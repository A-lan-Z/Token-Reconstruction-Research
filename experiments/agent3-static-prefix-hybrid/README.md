# Reproduce the fixed static-public-prefix hybrid pilot

This new study preserves PR25 as development evidence. The exact pinned B1 is step13000 expanded_fixed_replication_1, not the newer continuation. All target snapshots are the existing P12 base/64/128/256 trajectory. There is no recovered-prefix maintenance.

Run commands from the agent3-static-prefix-hybrid worktree with Python3.12.3, torch2.10.0+cu128, transformers5.3.0, safetensors0.7.0, numpy1.26.4 and scipy as recorded in environment receipts. CUDA FP32 proposers share the exact fixed CPU-normalized public readout; the public prefix is BF16 SDPA. Record batch1; candidate batchK16 orK256, no numerical microbatch workaround. The P11/P12 native selector, direct cosine rule and public-prefix loader remain unchanged. The B1 package is loaded in an isolated import context so its exact preserved modules coexist with native A2.

The interfaces below are create-only. On another host restore actual assets and bind their new paths rather than rewriting historical evidence. Model/package originals and independent Windows backup inventories identify exact bytes. Native source/target assets remain in the sibling TRR-P12 worktree; no other agent's private evaluation truth is needed.

1. Read `plan.md` and the saved owner request. Tests: `OMP_NUM_THREADS=2 python3 -m pytest -q tests/agent3_hybrid`.
2. Development qualification: `python3 -m scripts.agent3_hybrid.watchdog --output <new-guard-dir> --max-seconds 900 -- python3 -m scripts.agent3_hybrid.qualify --output <new-qualification-dir>`. The retained accepted run is qualification-r2; r1 is an excluded import collision before inference. All four qualification clips are already-opened PR25 data. Native anchors, instrumentation, own caches and repeated predictions are checked. CUDA differed from prior CPU B1 at one of508 top1 positions; no CPU/GPU equality is claimed.
3. `python3 -m scripts.agent3_hybrid.freeze_implementation` binds the qualified implementation and exact model files, verifies independent actual public-model backup bytes, and freezes the fresh selection rule. Historical freeze is immutable.
4. Evaluator-only selection: `python3 -m scripts.agent3_hybrid.curator select --output <new-source-dir>`. Frozen selection seed5103; Pile[0,10000), Finance[50000,52000);32 eligible records/domain. Trusted rendering and identity exclusion precede any reconstruction outcome.
5. Eight evaluator-only capture jobs: see `orchestration/capture_matrix.py` and `capture-execution/*/command.json`. Production capture uses the qualified P12 cut4 full-sequence prefix path, B8×192 with128 active positions; it releases only BF16 activations, masks and positions. The public base/target adapter bytes are verified; no new target is trained.
6. `python3 -m scripts.agent3_hybrid.run_matrix` runs eight isolated guarded cells. Each cell runs all five fixed arms with arm order rotated by record, one warmup and three measured whole reconstructions per arm/record, exact repeat checking, and separate native cache per invocation. `execution/*/command.json` records exact commands and commits. Do not change the execution commit or frozen code during the matrix. `orchestration/gpu_activity.py` samples CUDA application presence.

This verifies all methods, paired sources, predictions, retained direct-cosine winners, cache traces, repeats and code identities before truth.

Whole warmed times include common instrumentation and diagnostic trace materialization; per-phase candidate time includes candidate-cache cloning/branching and simulation. Cache-commit time is separate. Cold loading, output I/O, warmups and all candidate counts are retained. A2 repetitions recreate proposals and their own causal caches. No teacher prefix, another method's reconstruction, fallback, centering change, or post-label revision is allowed.

This fixed pilot is not the full dual-canonical matrix or proof of population equivalence. Report every domain and snapshot, the prospective quality/20% speed criteria, source-record uncertainty, B1-alone comparison, and causal-attribution limitations before any further variants.
